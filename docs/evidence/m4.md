## Failures encountered and repaired

1. Initial gemini-2.5-flash-lite availability failed before tools. Preserved chat-create-first-failure.json/reservation; selected M0-verified3.5 model. No silent expensive fallback.
2. Incorrect today-date across IST midnight: technically successful model run failed semantic acceptance. Evidence retained; explicit current local date/Calendar omission guidance and actual list membership assertion repair it.
3. Root SPA Ingress shadowed /mcp: separate low-priority root Ingress preserves protocol routing. Empty JSON content type on DELETE blocked removal: header only with a body. Deleted upstream names formerly remained globally unique: partial active-name index preserves immutable IDs/history and permits recreation.
4. Test fixtures assumed wrong audit-source enum and filtered revoked rows out of their locator; corrected to established delegation/key contracts and verified next-call denial. Earlier failures retained, not presented as passing product defects.
5. Synced workspace reads/builds were slow. Docker no-space outage recovered without deleting state. Regenerable caches only were cleaned under owner authorization. npm download resets retried by package manager while retaining frozen versions. One regression was started during rollout and received temporary AUTH_STORE_UNAVAILABLE; its output is retained in regression-during-rollout.txt and it was rerun after completion.
6. Visual review repaired mobile answer clipping, narrow technical table columns, cramped search, empty-policy feedback, discovery loading and stale reservation text. Captures wait for animation completion so transient transparent frames do not masquerade as final UI.

## Decisions and limitations

See ADR0009. Independent durable chat turns; no unbounded conversation memory. Cancellation targets the active API process; cross-replica recovery remains M8. An interrupted mutation requires store/audit reconciliation, never blind retry. No SMTP, OAuth, HA storage, public TLS, VPS or amd64 proof claimed. Standard NetworkPolicy bounds provider egress by IP/category; application fixes the official hostname/redirect behavior, not an FQDN firewall. Operator privileges can still exec/port-forward. M4 inspector is supporting work for C1, not the complete Flight Recorder. All B/D/S/C scope remains active.
