# Bounded model provider

The pinned AI SDK Google adapter runs Gemini through the reviewed HTTPS endpoint. Durable prepaid reservations precede provider traffic; request/output/step/tool bounds prevent unbounded loops. Secrets stay in the API workload. Tool discovery/execution is delegated to the authenticated gateway, not performed directly against WooCommerce.

See the root README, model provider source and docs/THREAT_MODEL.md for actual behavior and remaining limitations. Local fallback and unimplemented future model capabilities are not claimed.
