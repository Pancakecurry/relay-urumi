# WooCommerce MCP

Handwritten REST v3 adapter: list_products, create_product, list_orders, get_order, update_order_status, and the intentionally shared info tool. Strict schemas and bounded Streamable HTTP; credentials are read from mounted files only. See ../../docs/runbooks/mcp-upstreams.md and ADR 0007. No prebuilt Woo MCP plugin.
