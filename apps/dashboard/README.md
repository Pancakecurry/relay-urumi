# Relay dashboard

React/Vite Control Room with authenticated overview, upstream and tool workspace, real gateway chat inspector, audit explorer, team invitations/permissions, personal API keys, OAuth client management and durable multi-store orchestration. TanStack Query handles server state; accessible project-owned components/styles use the documented design tokens.

Run the root production build or dashboard:build command. Real browser verification and current deployment instructions are linked from the repository README and docs/release/TEST_EVIDENCE.md. No production mock backend is used.
